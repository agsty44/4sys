# 4sys — Documentation

This folder contains an initial, human-readable summary of the codebase, architecture, and a short security review created as part of a code review.

Files in this directory:
- `file_inventory.md` — list of important files and entry points
- `architecture.md` — overview of authentication flow, pages and APIs
- `security_review.md` — quick findings and prioritized issues
- `next_steps.md` — recommended actionable next steps and low-risk fixes

Note: I did not modify any existing source files; these documents only describe what I observed.
